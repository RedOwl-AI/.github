# RedOwl-AI/.github

This is RedOwl’s special GitHub organisation repository. The public organisation profile README lives in [`profile/README.md`](profile/README.md) and is shown on [github.com/RedOwl-AI](https://github.com/RedOwl-AI).

GitHub only renders that profile when this repository is **public** and `profile/README.md` is present on the default branch.
